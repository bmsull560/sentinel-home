# Security Findings

This directory stores penetration test findings and the final report.

## Naming convention

Each finding is a Markdown file named `SH-YYYY-MM-###.md` using the template in `../FINDINGS_TEMPLATE.md`.

## Files

- `final-report-YYYY-MM-DD.md` — consolidated penetration test report
- `SH-YYYY-MM-###.md` — individual findings

Do not commit raw exploit output containing real credentials or PII. Redact sensitive values before committing.
